# Agent instructions

## Version control (jj)

- Before handing back to the user, get your changes into source control:
  describe the working-copy change with `jj describe -m "..."`, then run
  `jj new`. Never hand back with undescribed changes in the working copy.
- Leave the `main` bookmark and pushing to the user.
- Keep the first line of a description under 70 characters. Up to 80 is
  okay, but aim for under 70.
